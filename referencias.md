# Referências (ABNT — NBR 6023)

Referências utilizadas no projeto **Pipeline Multi-Agente Reflexivo para Qualidade de
Código Python** — Grupo 6 (G6), Tópicos em Engenharia de Software, PUC-Campinas.

ANTHROPIC. **Building Effective Agents**. 2024. Disponível em: https://www.anthropic.com/research/building-effective-agents. Acesso em: 10 jun. 2026.

SHINN, Noah et al. **Reflexion**: language agents with verbal reinforcement learning. arXiv, 2023. arXiv:2303.11366. Disponível em: https://arxiv.org/abs/2303.11366. Acesso em: 10 jun. 2026.

WANG, Lei et al. **Plan-and-Solve Prompting**: improving zero-shot chain-of-thought reasoning by large language models. arXiv, 2023. arXiv:2305.04091. Disponível em: https://arxiv.org/abs/2305.04091. Acesso em: 10 jun. 2026.

SUMERS, Theodore R. et al. **Cognitive Architectures for Language Agents (CoALA)**. arXiv, 2023. arXiv:2309.02427. Disponível em: https://arxiv.org/abs/2309.02427. Acesso em: 10 jun. 2026.

PYLINT. **Pylint**: static code analyser for Python. Documentação oficial. Disponível em: https://pylint.readthedocs.io. Acesso em: 10 jun. 2026.

PYCQA. **Bandit**: a tool designed to find common security issues in Python code. Documentação oficial. Disponível em: https://bandit.readthedocs.io. Acesso em: 10 jun. 2026.

PYTEST. **pytest**: helps you write better programs. Documentação oficial. Disponível em: https://docs.pytest.org. Acesso em: 10 jun. 2026.
